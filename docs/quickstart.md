# ProtoLens Quickstart

ProtoLens helps you share static prototype files from GitHub and collect anchored review comments.

## 1. Sign In

Open:

https://protolens.myagenthubs.com

Sign in with GitHub.

## 2. Install The GitHub App

Install the ProtoLens GitHub App on the repositories that contain prototype files.

For the fastest first run, select only the repositories you want ProtoLens to review. You can add more repositories later from GitHub App settings.

## 3. Discover Prototypes

Return to the ProtoLens dashboard.

Choose a repository and ref. ProtoLens discovers static prototype files such as:

- `index.html`
- `docs/demo.html`
- `preview.svg`
- `mockup.png`

Files that are too large or unsupported will be marked as unavailable.

## 4. Share A Review Link

Each reviewable file gets a stable review URL.

Use the copy button to send the link to teammates. Anyone with the review URL can open the prototype according to the permissions encoded in that link.

## 5. Collect Comments

Reviewers can switch into review mode, click the prototype, and leave a comment. Comments are attached to the selected element, selected text, or clicked position.

Reviewer name is required so exported feedback stays attributable.

## 6. Export Feedback

Owners can export comments as Markdown from the dashboard. Individual prototype rows show per-file comment counts and per-file export controls when comments exist.

AI tools can also retrieve feedback through the ProtoLens MCP server.
